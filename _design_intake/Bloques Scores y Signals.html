Bloques · Scores & Signals

Bloques reutilizables del sistema arroba. Los Scores resumen una dimensión en un anillo de 0–100 con su nivel de confianza; las Signals comunican hallazgos en lenguaje condicional. Todo lo generado por inteligencia se marca con ✦. Cada bloque define cuatro estados: con datos, cargando, vacío y error / dato no disponible.

Anatomía y uso
Score
Score {
  label: "Calidad",
  value: 82, // 0–100
  tone: "success|info|red|warning",
  confidence: "alta|media|baja",
  confidencePct: 88,
  state: "data|loading|empty|nd"
}
Si state ≠ data, el anillo NO muestra número: pasa a skeleton (loading) o a trama discontinua + "s/d" (no disponible). La confianza siempre visible.
Signal
Signal {
  tone: "success|info|warning|red",
  text: "Hecho observado (afirmación neutra).",
  implication: "Podría / tendría… (condicional)",
  confidence: "alta|media|baja"
}
La implicación usa siempre lenguaje condicional ("podría", "tendría"), nunca afirmaciones tajantes. Acompañada de su confianza.
